# 设计参考

- `three-screen-concept.png`：书架、扫描和双页阅读的视觉方向。
- `page-annotation-concept.png`：页面结构标注，票根选区和交互类型。
- `reader-concept.png`：掀起票根与抽出夹页的阅读状态。
- `product-structure.html`：先前会话中的产品结构可视化源文件，依赖会话的样式变量，并非独立网站。

三张概念图由内置图像生成工具制作，用于评审视觉方向；图中的手账为生成样例，不是用户扫描件。

提示词的共同约束：暖米白纸张、深墨绿和朱砂色、克制纸张阴影、清晰原生移动端层级、中文主要标签、没有人物与水印。分别要求三屏总览、票根框选状态，以及真实固定边掀起/书脊夹页抽出的阅读状态。

实际应用以 SwiftUI 原生控件实现。概念图中的文字、透视和层次不作为像素级实现依据；交互与数据规则以产品文档为准。
